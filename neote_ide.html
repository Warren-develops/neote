Neote Language Reference & Rules

                
            

            

                

                    

                        
Core & Variables

                        

                            
st name = "Neote" → variable

                            
eval("2 + 2") → evaluate math

                            
addPhrase(p, v) → custom syntax

                            
keep(k, v) / grab(k) → storage

                        

                    

                    

                        
Modals & Media

                        

                            
cover("Hi") → alert popup

                            
qstn("Age?") → prompt input

                            
img(url) → <img> element

                            
vid(url) / aud(url) → media

                        

                    

                    

                        
Operations & Loops (Expanded)

                        

                            
if(a => b) {} → equality check (a == b)

                            
else if(a => b) {} → else if

                            
else {} → fallback branch

                            
repeat(5) {} → loop N times

                        

                    

                    

                        
UI Elements & Events

                        

                            
$button(text, class) → <button>

                            
$(text, class) → <div>

                            
$p(text, class) → <p>

                            
$footer(text, class) → <footer>

                            
on click("class") {} → click event

                        

                    

                

                

                    
CSS Class Styling & Storage

                    
st my-btn = {
    background: #9333ea;
    color: white;
    padding: 10px 20px;
    border-radius: 8px;
}
keep("score", 100) // Save data
st saved = grab("score") // Load data
