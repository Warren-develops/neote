Tips & tricks

Get more out of the Neote language and the IDE.

Keyword shortcuts
st→ let
showcase(...)→ console.log
notify(...)→ alert
qstn(...)→ prompt
$ DOM loaders
$hd("t") → header
$btn("t") → button
$p("t") → paragraph
$div("t") → div
$input("ph") → input
$img("src") → img

Add inline attrs: $btn("Go") /id="go"

Keyboard shortcuts
  • Run codeCtrl + Enter
  • Save fileCtrl + S
  • Toggle explorerCtrl + B
  • AutocompleteCtrl + Space
  • Toggle terminalCtrl + `
Workflow tips
  • Run terminal.help() in the IDE CLI for the full command reference.
  • Drag & drop files onto folders in the explorer to reorganize your project.
  • Use Popout to open the compiled app in a dedicated window.
  • Filter the tree by date to find what you touched in the last 24h.
